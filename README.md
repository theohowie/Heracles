# Heracles

**手机上的开发智能体** —— 一个跑在 Android 上的 AI 编程 App。

你打字描述一个需求，它在你手机上的**真实工作区**里读代码、改文件、跑命令；
接上设备侧工具链之后，它还能**直接在这台手机上**把 Android 工程构建成可安装的 APK。

模型用**你自己的 API Key**（BYOK）跑在云端，手机上不加载任何模型。

> **版本 v0.2.0** · **Android 12（API 31）+ · arm64** · **GPL-3.0**
>
> 📖 图文简介与快速开始：**https://theohowie.github.io/Heracles/** ｜ ⬇️ [下载 APK](https://github.com/theohowie/Heracles/releases)
>
> **alpha 阶段**：接口、UI、工具面都还会变。能用的与还不能用的，见 [功能与限制](#功能与限制)。

## 它有什么用

| 场景 | Heracles 怎么帮你 |
|---|---|
| **手边没有电脑，想改几行代码** | 把手机上的项目目录加成工作区，说清楚要改什么；它读文件、局部替换、改完把 diff 给你看 |
| **想让 AI 带着上下文看代码** | 工作区里的文件能列、能读、能按文件名/内容搜索，长文件自动分段 |
| **想在这台手机上构建 APK** | 设备侧工具链就绪后，走 `aapt2 → javac → d8 → 进程内对齐 → 签名`，直接产出可安装的 APK（不需要 Gradle） |
| **想改一个现成的 APK** | 解包（资源或 smali）→ 改 → 重打包 → 签名 → 装回去，改的文案在界面上生效 |
| **只是想有个手机上的编程助手** | 不带工作区也能聊；多轮工具调用、任务计划、随时中断 |

工具面（模型能调用的动作）大致分四类：

- **文件与搜索**：列目录、读文件、写文件、局部补丁、按名查找、按内容搜索、建目录、删除/移动/复制
- **执行与交互**：在设备上跑 shell 命令、记住项目偏好、向你提问、按需披露长尾工具
- **构建与逆向**：生成 Android 工程、构建 APK、反编译、重打包、签名
- **计划**：模型先给出一份任务计划，界面上按真实执行结果逐步打勾

## 界面与操作

- **会话页**：两层顶栏（品牌图标 + 会话名 + 上下文/命中双指标）、对话 + 工具调用卡片、
  任务计划、流式状态、输入区（模型/思考档位胶囊 + 附件 + 发送/停止/排队）
- **侧边栏**：工作区与会话列表，可加多个工作区、随时切换；工作区行长按出菜单（新建会话 / 从列表移除）
- **设置**：通用（语言 / 字号 / 工作步骤 / 忙时发送 / 最大轮次）· 全局记忆 · 设备权限 · 模型 · 外观
- **空态**：大字问候 + 一组建议胶囊，点一下就开跑

## 三步用起来

### 1. 装 App

从 **[下载与安装](#下载与安装)** 里的 Release 附件装 v0.2.0 的 APK（或自己构建），要求 **Android 12（API 31）及以上**、**arm64** 手机。

### 2. 配模型

`设置 → 模型 → 添加`，填四样：

| 字段 | 说明 |
|---|---|
| **API 协议** | `OpenAI 兼容`（最常见）/ `Anthropic` / `Responses` |
| **Base URL** | 例如 `https://api.deepseek.com/v1`、`https://dashscope.aliyuncs.com/compatible-mode/v1`，也可以是自建 vLLM 或中转站 |
| **API Key** | 只存在手机本地（安全存储），只出现在请求头里，不进日志 |
| **模型名** | 可点「获取可用模型」从 `GET {baseUrl}/models` 拉列表 |

> **建议选支持 function calling 的模型**：原生工具调用是验证过的那条路；
> 不支持的模型会退回文本 JSON 协议（能跑，但稳定性差一截）。

### 3. 加工作区，开聊

侧边栏 `⊕` 有两个入口：

- **选择文件夹**：用系统文件选择器（SAF）授权任意目录，包括 `/sdcard` 上你自己的项目
- **默认工作区**：App 自己的私有目录，不用授权，适合第一次试手

然后像跟人说话一样描述任务。越界的动作按权限档位处理：**允许 / 需要确认 / 拒绝**。

**长任务的样子**：构建一次 APK 要 1–3 分钟，期间 App 会起前台服务保住进程、通知栏实时显示步骤；
手机太热（44 °C）会主动**暂停** —— 这是设计好的保护，不是崩溃。

### 可选：解锁「在手机上构建 APK」

构建/逆向类工具依赖一套**设备侧工具链**：Termux 的 bionic 版 `openjdk-17` / `aapt2` / `d8` /
`apksigner` / `smali`，摊成一棵前缀树（约 244 MB，默认 `/data/local/tmp/heracles/toolchain`）。
不装它，聊天、读写文件、搜索都照常，只是构建/逆向类工具会**明确报错**（不会假装成功）。
装配脚本不随本仓库发布。

**在设备上执行 shell 命令**这条路由需要 **Shizuku**（或增强分支 Stellar）：
装好后在 `设置 → 设备权限` 一键授权，页面会显示当前走的是哪条路由。

## 功能与限制

### 已经可用

已在真机（Android 17 / arm64）上跑通：

| 能力 | 验证方式 |
|---|---|
| 会话页、设置页、工作区抽屉、空态 | 真机操作 + 界面结构核对 |
| 事件流与会话守卫（切会话 / 移除工作区时，在途结果不串台） | 真机复现 + 组件测试 |
| 审批门禁（"始终允许"跨运行持久化，清除后恢复询问） | 真机复现 + 运行日志 |
| 取消、排队发送、上下文压缩 | 真机复现 |
| 设备权限总览（Shizuku / 文件访问 / 所有文件访问 / 通知 / 无障碍 / 悬浮窗） | 真机读数 + 截图 |
| 内核（编排 / 工具 / 契约） | `backend/` 269 项 Dart 单测全绿 |

### 尚未实现或尚未验证

- **线上字段的真 Key 验证还没做过**：`tools` 形状、思考参数等只有静态检查与单测覆盖。
- **Anthropic / Responses 两条协议轨**：只验过 OpenAI 兼容那条。
- **图片多模态**：能上传图片，但模型只拿到文件名与字节数。
- **在 SAF 工作区里构建**（读进来 → 私有目录构建 → 产物写回）只在单测里通过。
- **一轮多个工具调用**：目前串行，只执行第一个。
- **机型覆盖**：只在一种设备、一种字体下验证过。
- **正式发布签名**：release 变体暂用 debug key（见 [已知问题](#已知问题)）。

### 质量门禁

`backend` 269/269 · `flutter analyze` 无 issue · 组件测试按文件跑
（`widget_test` 17 · `session_guard` 12 · `reasoning_switch` 37 等）；另有真机冒烟与布局测量。

## 已知问题

| # | 问题 | 影响 |
|---|---|---|
| 1 | **release 用 debug 密钥签名** | `apksigner` 核验：仅 v2 方案、签名者 `CN=Android Debug` ⇒ 能装能用、能覆盖当前同签名安装，但**不能上架 Play、也不能被将来正式密钥的包覆盖升级**（换 key 要先卸载，会删数据） |
| 2 | **只支持 arm64 机型** | Flutter 引擎只带 `arm64-v8a`；badging 里出现的 `armeabi-v7a`/`x86_64` 只是两个插件的 `.so` ⇒ **32 位手机装上也起不来**（要纯单 ABI 可用 `--split-per-abi`/`abiFilters` 再收紧） |
| 3 | **真 Key 未验证** | 换用不常见的中转站/协议时，可能出现服务端 400 之类的问题 |
| 4 | **图片看不懂** | 附件里选图片只会传文件名/字节数 |
| 5 | **一轮多个工具调用只执行第一个** | 多花一轮，任务变慢 |
| 6 | **只在一种机型验证** | 其它机型的温度、权限、文件系统行为都没有数据 |
| 7 | **`flutter test` 个别文件会卡死** | 开发机本地回环被拒（`errno 10013`）或缺少插件通道 mock；**改成单文件跑**即可 |
| 8 | **UI 正在快速迭代** | `frontend` 分支上还在改版式；窄屏（≤390dp）输入行的溢出风险仍在收敛中 |

## 从源码构建

**要求**：Flutter 3.44.2（Dart SDK `^3.12.2`）· JDK 17 · Android SDK（`compileSdk 37`）· adb。
`backend/` 是**纯 Dart 包**，不需要 Flutter。

```bash
# 1) 内核（编排 / 工具 / 契约）—— 纯 Dart，最快最稳
cd backend
dart test                                   # 269 项

# 2) 前端
cd ../app
flutter pub get
flutter analyze                             # 期望：No issues found!
flutter test test/widget_test.dart          # 建议逐文件跑（见已知问题 7）
flutter test test/session_guard_test.dart

# 3) 打包 / 装机
flutter build apk --release --target-platform android-arm64
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

⚠️ 同一命令链里**不要连着跑多个 Gradle 任务**（daemon 抢端口会假失败）—— 逐条跑、看退出码 +
产物 mtime/sha256，别只看输出文字。

## 注意事项

- **BYOK，费用自负**：推理都走你自己的 Key；模型能力直接决定体验上限。
- **自动执行有风险**：它会在你授权的工作区里改文件、跑命令 —— 请只授权项目目录，别授权敏感目录。
- **构建/逆向需要额外部署**：没装设备侧工具链时，相关工具只会失败并说明原因。
- **接口会变**：alpha 阶段没有兼容性承诺。
