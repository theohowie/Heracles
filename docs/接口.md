# 接口.md —— backend → App 的全部接口面

> **用途**：backend（`backend/`，纯 Dart 包）与前端（`app/`，Flutter 宿主）之间的
> **每一处接口**都记录在这里。改接口必须先改这里 —— 这是唯一权威，两边代码照它对齐。
>
> **方向约定**：
> - **backend 提供**（App 消费）：类型、常量、`HeraclesAgent` 运行 API、事件流；
> - **backend 要求宿主实现**（App 注入）：`AskGate`（提问/审批）、`Capabilities`（设备能力）、
>   状态存储（可选）。backend 不 import Flutter，App 不 import `dart_agent_core`
>   （那只是 backend 的传递依赖，见 `multimodal.dart` 文件头的边界论证）。
>
> 最后更新：2026-10-24（+ 子代理 delegate_task 接线（H6））。

## 1. 运行入口：`HeraclesAgent`

来源：`backend/lib/src/agent/heracles_agent.dart`（经 `heracles_backend.dart` 导出）。

### 1.1 构造

```dart
HeraclesAgent({
  required BackendConfig config,
  required Capabilities capabilities,
  RunOptions options = const RunOptions(),
  StateStorage? stateStorage,   // 框架状态持久化；App 不用（会话由宿主存）
```

### 1.4 `ApprovalMode`（审批档位，2026-10-24 新增）

```dart
enum ApprovalMode { manual, workspaceAuto, fullAccess }
```

对应 App 设置的三档权限模式。**库默认 `fullAccess`（不拦）**——库没有 UI 可问；
App 必须显式从 `settings.permission` 映射传入。拦截由 backend 的 `_ApprovalHook`
在工具执行前执行，"问谁/白名单"由宿主的 `AskGate.requestApproval` 决定。

各档需要批准的工具集：

| 档位 | 需批准 |
|---|---|
| `manual` | 写文件四件套（write_file/edit/apply_patch/mkdir）+ 破坏性三件套（delete_path/move_path/copy_path）+ run_shell_command + APK 五件套 |
| `workspaceAuto` | 破坏性三件套 + run_shell_command + APK 五件套 |
| `fullAccess` | 无 |

所有档位之上还有两道**恒定闸**：shell 硬禁令（kill/force-stop 等，`shell_tools.dart`）
与 SSRF 防护（`web_fetch`，App 侧实现）。

### 1.5 `run()`（一次完整任务）

```dart
Stream<HeraclesEvent> run(
  String userRequest, {
  List<LLMMessage>? history,   // 跨轮记忆：调用方从会话文件回填（原样、正序、不含本轮请求）
  List<ImageInput>? images,    // 图片附件（§5）；调用方负责视觉能力判断
  CancelToken? cancelToken,    // 真取消：cancel() 后框架在轮次边界停 + 在途 HTTP 流被掐断
})
```

事件流在任务结束时关闭；消费端提前离开也要等生产者收尾（`run` 内部保证）。

### 1.6 `contextBreakdown()`（C5 构成统计，2026-10-24 新增）

```dart
Map<String, int> contextBreakdown()   // {'system', 'tools', 'history'}（估算 token）
```

`system` = 默认提示 + 宿主追加 + 宪法/快照 + **分层记忆**（global → workspace → session，最末是跨层冲突尾注；都进 system 消息）。
与压缩器同一套 CJK 估算（`WindowRatioCompressor.estimateText` 等**静态入口**）。
App 链路：`LocalAgentExecutor.lastBreakdown` → `AgentBridge.lastContextBreakdown()` → 侧栏"构成"三行。

### 1.7 手动压缩：`summarizeTranscript()`（/compact，2026-10-24 新增）

```dart
static Future<String> summarizeTranscript({
  required BackendConfig config,
  required String transcript,
  int maxChars = 4000,
  LLMClient? client,   // 测试注入点；生产不传 = 按配置现建
})
```

一次性裸 `generate`（不进 agent 循环）。**摘要为空/失败向上抛，绝不静默返回空**
—— 空摘要写进标记行 = 用户以为压了、实际全丢。

App 链路：输入框敲 `/compact`（`chat_screen._runAgent` 拦截，忙时继承排队语义）
→ `AgentBridge.compactSession()`：读会话 user/assistant 正文 + 工具结论（各截 200 字符，
尾部 5 万字符）→ 摘要 → **追加**一行 `{role:"compact", summary}` 到会话尾部
（append-only：原始记录一字未动）→ 下次回填时 `sessionRowsToHistory` 遇到该行
丢弃之前的一切、只带摘要进场。

### 1.9.2 计划落盘与注入防御（2026-10-24 新增）

- **计划落盘（M2）**：App 侧每次 `HeraclesPlanUpdated` 追加一行
  `{role:"plan", steps:[{text,status}], ts}`（status ∈ pending/active/done/cancelled）。
  回填（`sessionRowsToHistory`）取**最后一行**在末尾合成一条
  `[恢复会话] 此前的任务计划…` 的 user 消息（模型侧恢复）；UI 重载读同一行还原顶部清单。
- **web_fetch 注入包裹（SEC1）**：成功结果被**无条件**包裹为
  `【外部网页内容开始 · 来源：url】…【外部网页内容结束】` + 夹带指令处理规则；
  失败结果原样透传。文件内容与命令输出暂未包裹（只有 system 边界句）。

### 1.9.1 "先读再改"强制（K1，2026-10-24 新增）

`EditReadTracker`（`tool_factory.dart`）随工具列表创建（App 每次 run 一个）：

- `edit` / `apply_patch`：目标路径必须**被读过**或**本会话写过**，否则拒绝
  （拒绝信息指路 read_file）；
- `write_file`：覆盖**已存在**文件同上；**新文件**随便写；
- `delete_path` 失效记账、`move_path` 迁移记账；
- 边界：无 mtime 防陈旧（v1）、路径字符串从宽、子代理与主线程共享记账。
- 测试：`test/read_before_edit_test.dart` 8 条。

### 1.9 子代理（H6，2026-10-24 新增）

`enableSubAgents: true` ⇒ 模型可调 `delegate_task(assignee, task_description)`：

- **`assignee: "worker"`** = 本库注册的干净上下文 worker：全新 `AgentState`（看不到主对话，
  `task_description` 必须自包含）、独立事件总线（过程事件就地丢弃，不污染主线程的
  用量记账与 UI）、`maxTurns: 12`、**禁止再派生**（深度恒为 1）；
- **`assignee: "clone"`** = 框架自带：主对话历史拷进情景记忆的"带记忆分身"；
- **hooks 照常继承**：worker 的危险操作照样弹审批、调用照样计入任务总预算
  （不能靠派生绕过门禁）；
- worker 的最终结论以 `delegate_task` 的工具结果回到主线程 —— 主上下文只收结论。

### 1.10 宿主注入 system prompt 的两段新内容（2026-10-24）

| 注入物 | 来源 | 上限 |
|---|---|---|
| 工作区宪法 | `fs.readText` 读 AGENTS.md → CLAUDE.md → README.md（第一个存在的） | `ContractWorkspace.constitutionMaxChars` = 20000 字符，超限截断明说 |
| 工作区快照 | `fs.list` 递归（相对路径清单，跳过 `.heracles/`） | `ContractWorkspace.snapshotMaxEntries` = 200 项，超限明说 |

## 2. 事件流：`HeraclesEvent`（sealed，switch 穷尽）

`agent.run()` 逐个产出，App 的 `_Translator`（`local_agent.dart`）翻译成 UI 的 `AgentEvent`。
右侧"UI 事件"列为 `agent_bridge.dart` 里对应的事件名。

| 事件 | 字段 | 语义 | → UI |
|---|---|---|---|
| `HeraclesTextDelta` | delta | 正文增量（**最终回答只认它**） | `step_delta` |
| `HeraclesThoughtDelta` | delta | 思考增量（与正文严格分离，绝不合并） | `reasoning_delta` |
| `HeraclesRetrying` | reason | 模型调用重试中（瞬态，不播 UI） | （日志探针） |
| `HeraclesBudgetWarning` | used, limit | **预算预警**（2026-10-24）：工具调用预算用到 75%/90% 各播一次 | `blocked` 卡片 |
| `HeraclesToolRequested` | toolName, arguments, id | 模型发起工具调用（id=框架调用 id，宿主落盘 tool_call 行用） | `tool_started` |
| `HeraclesToolFinished` | toolName, isError, output, durationMs, metadata, id | 工具执行完（**被拒绝的调用也有此事件**，isError=true；id 与 Requested 配对） | `tool_finished` |
| `HeraclesPlanUpdated` | steps[]（text,status） | 计划变化 | `plan_created` |
| `HeraclesContextCompressed` | beforeMessages/afterMessages/beforeTokens/afterTokens | 上下文已压缩（有损，必须让用户看见） | `context_compressed` |
| `HeraclesTurnUsage` | promptTokens, outputTokens, cachedTokens? | 逐轮用量（provider 上报；cachedTokens=null=未上报，UI 显示"不可用"） | 顶栏/侧栏记账 |
| `HeraclesFinished` | finalText, turns, totalToolCalls, wallClockMs | 正常收尾 | `finished` |
| `HeraclesFailed` | reason | 失败收尾（含预算超限/循环检测的措辞） | `failed` |

## 3. 宿主必须实现：`AskGate`

来源：`backend/lib/src/agent/tools/interaction_tools.dart`。App 实现 = `LocalAskGate`
（`app/lib/services/local_agent.dart`），桥接层每次 run 创建一个并通过静态指针路由回答。

```dart
abstract class AskGate {
  /// ask_user 工具：挂起等回答（超时/取消 = null，绝不编造答案）。
  Future<String?> askUser(List<AskQuestion> questions);

  /// 审批：_ApprovalHook 在工具执行前调用。
  /// 返回 true=放行执行；false=该工具以"用户拒绝"的合成失败结果回给模型。
  ///
  /// 实现约定（宿主必须遵守）：
  /// · 白名单先行：宿主自持的「始终允许」名单命中直接回 true（后端不感知白名单）
  /// · 挂起等用户决定，绝不发完事件就返回
  /// · 拿不到答案（超时/关闭/通道不可用）= false（fail-closed）
  Future<bool> requestApproval(
    String toolName,
    Map<String, String> args,  // 参数字符串化，弹窗展示完整内容，不截断
    String detail,             // 一句人话摘要（弹窗原因行）
  );
}
```

**审批链路时序**（2026-10-24）：

```
模型发起工具调用
  → _ApprovalHook.beforeToolCall（档位判定）
  → AskGate.requestApproval                      [backend]
  → LocalAskGate 发 AgentEvent(kApprovalRequest)  [App，事件字段 tool/args/reason]
  → chat_screen._showApprovalDialog（允许/始终允许/拒绝/停止任务）
  → AgentBridge.replyApproval('once'|'always'|'deny')   // 2026-10-29 口径统一：旧值 'allow'|'allow_always' 仍接受（兼容），**落盘 role:"approval" 一律写 once/always/deny**
  → LocalAskGate.replyApproval → 完成挂起
       ├ allow        → hook proceed，工具执行
       ├ allow_always → 放行 + onAlwaysAllow(tool) 回调持久化 + run 内免问
       └ deny/超时    → hook deny，模型收到"用户拒绝"（劝其换路，勿原样重试）
```

配套：`AskQuestion{id, question, multi, options[]}` / `AskOption{label, description?}`。

| 能力 | 接口方法（摘要） | App 实现 |
|---|---|---|
| `WorkspaceCapability` | list/read/write/edit/applyPatch/mkdir/delete/exists/findFiles/grepFiles/move/copy | 走设备文件通道（含 SAF）；路径越界防护在实现内 |

## 7. 记忆分层（三作用域，2026-10-29 新增 · 后端落码中）

> 对外契约以 `docs/INTERFACE.md` §N12 为准；本节是**后端实现面**清单。设计依据：`.docs/记忆系统重设计-2026-10-29.md`（§三/§四/§六）。
> ⚠️ **验收状态**：Kotlin 通道 / backend 渲染落码中；真机迁移、会话隔离、全局只读、提议晋升**均未验证**。

### 7.1 存储与寻址

| 项 | 实现 |
|---|---|
| 三作用域 | `MemoryScope.session`（绑定 `(workspacePath,sessionId)`）/ `workspace`（`workspacePath`）/ `global`（App 级） |
| 文件布局 | workspace/session → `<ws>/.heracles/memory/{workspace.jsonl, session/<sid>.jsonl, index.json}`（Dart 经 `fs.*`）；global → `<externalFilesDir>/heracles/memory/{global.jsonl, proposals.jsonl, index.json, migrate.json, legacy/}`（Kotlin 通道） |
| 为什么会话记忆不进会话 `.jsonl` | 会话正文永久 append-only；记忆单独成文件才能安全 compact（墓碑+重写），且不挤占历史读取窗口 |
| 寻址强校验 | `MemoryAddress` 8 步（INTERFACE §N12.4）；**失败一律 fail-closed**，绝不回落 global/workspace/默认实例 |
