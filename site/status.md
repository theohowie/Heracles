## ⬜ 还没做 / 还没验（不淡化）

- **真 Key 的线上字段验证一次都没做过**：`tools` 形状、思考参数等 wire 字段目前只有静态与单测覆盖。
  历史上真出过一次事故：把一个 provider 专有字段发给所有兼容端点，被中转站 **400**。
- **Anthropic / Responses 两条协议轨**：只验过 OpenAI 兼容那条。
- **图片多模态**：UI 能传图片，模型只拿到文件名与字节数。
- **SAF 工作区里构建**（读进来 → 私有 staging 构建 → 产物写回）只在单测里通过。
- **一轮多个工具调用**：目前串行，只执行第一个。
- **机型覆盖**：只在一种设备、一种字体下验证过。
- **正式发布签名**：release 变体暂用 debug key。

## 已知问题

| # | 问题 | 影响 |
|---|---|---|
| 1 | **release 用 debug 密钥签名** | 能装能用、能覆盖同签名安装；但**不能上架 Play，也不能被将来正式密钥的包覆盖升级**（换 key 要先卸载，会删数据） |
| 2 | **只支持 arm64 机型** | Flutter 引擎只带 `arm64-v8a`；badging 里出现的 `armeabi-v7a`/`x86_64` 只是两个插件的 `.so` ⇒ 32 位手机装上也起不来 |
| 3 | **真 Key 未验证** | 换用不常见的中转站 / 协议时，可能出现服务端 400 之类的问题 |
| 4 | **图片看不懂** | 附件里选图片只会传文件名 / 字节数 |
| 5 | **一轮多个工具调用只执行第一个** | 多花一轮，任务变慢 |
| 6 | **只在一种机型验证** | 其它机型的温度、权限、文件系统行为都没有数据 |
| 7 | **个别测试文件会卡死** | 开发机本地回环被拒（`errno 10013`）或缺插件通道 mock；**改成单文件跑**即可 |
| 8 | **UI 正在快速迭代** | 版式还在改；窄屏（≤390dp）输入行的溢出风险仍在收敛中 |
