# 快速开始

从装 App 到跑通第一个任务，大约五分钟。

## 1. 装 App

| 方式 | 说明 |
|---|---|
| **下载 APK** | [`Heracles-v0.2.0.apk`](https://github.com/theohowie/Heracles/raw/master/dist/Heracles-v0.2.0.apk) · **20.6 MB** · sha256 `F9F1E087AEF64D5333E27CDDC8813E51A2F9C4B0886B8A60CA0DAAD85D327DBC` |
| **自己构建** | 见 [从源码构建](/guide/build) |

要求：**Android 12（API 31）及以上**、**arm64 手机**。

::: warning 关于这个包
它是 **release** 构建，但**用 debug 密钥签名**（还没有正式发布密钥）⇒ 安装时要允许「未知来源」，
系统可能提示"来自未知开发者"。另外包内的 Flutter 引擎**只带 arm64-v8a**，32 位手机装上也起不来。
:::

## 2. 配模型

`设置 → 模型 → 添加`，填四样：

| 字段 | 说明 |
|---|---|
| **API 协议** | `OpenAI 兼容`（最常见）/ `Anthropic` / `Responses` |
| **Base URL** | 例如 `https://api.deepseek.com/v1`、`https://dashscope.aliyuncs.com/compatible-mode/v1`，也可以是自建 vLLM 或中转站 |
| **API Key** | 只存在手机本地（安全存储），只出现在请求头里，不进日志 |
| **模型名** | 可点「获取可用模型」从 `GET {baseUrl}/models` 拉列表 |

填完可以点「测试连通」，它会发一个只要 1 个 token 的最小请求，直接告诉你通不通。

::: tip 建议选支持 function calling 的模型
原生工具调用是验证过的那条路；不支持的模型会退回文本 JSON 协议 —— 能跑，但稳定性差一截。
:::

## 3. 加工作区，开聊

侧边栏 `⊕` 有两个入口：

- **选择文件夹** —— 系统文件选择器（SAF）授权任意目录，包括 `/sdcard` 上你自己的项目；
- **默认工作区** —— App 自己的私有目录，不用授权，适合第一次试手。

工作区行**长按**可以出菜单（新建会话 / 从列表移除，移除不会删文件夹本身）。

然后像跟人说话一样描述任务。越界的动作按权限档位处理：**允许 / 需要确认 / 拒绝**；
"本会话始终允许"会跨 run 记住，随时可以在设置里清除。

## 长任务是什么样

构建一次 APK 要 1–3 分钟。期间 App 会起一个**前台服务**保住进程，通知栏实时显示当前步骤；
手机太热（44 °C）会主动**暂停** —— 这是设计好的保护，不是崩溃。

## 可选：解锁「在手机上构建 APK」

构建/逆向类工具依赖一套**设备侧工具链**：Termux 的 bionic 版 `openjdk-17` / `aapt2` / `d8` /
`apksigner` / `smali`，摊成一棵前缀树（约 244 MB，默认 `/data/local/tmp/heracles/toolchain`）。

不装它，聊天、读写文件、搜索都照常，只是构建/逆向类工具会**明确报错**（不会假装成功）。
装配脚本属于开发脚手架，不在仓库内。

另外，**在设备上执行 shell 命令**这条路由需要 **Shizuku**（或其增强分支 Stellar）：
装好后到 `设置 → 设备权限` 一键授权，页面会显示当前走的是哪条路由。

## 安全与费用

- **BYOK，费用自负**：所有推理都用你自己的 Key，账单在服务商那边；
- **自动执行有风险**：它会在你授权的工作区里改文件、跑命令 —— **只授权项目目录，别授权敏感目录**；
- **Key 不进日志**：出错只记状态码与脱敏后的 URL。
